reslop

Open a change, leave findings and a backlog, and prepare a repair plan the agent executes.

Interactive code review · repair planning for AI-assisted changes

npm i -g reslop
GitHub Usage

Review, plan, repair, verify.

You

Review the change

Watch the change on a live dashboard. Keep a block, drop it, or write the fix you want. Feedback, tasks, and code proposals become the plan.

.review/*.md plan

Agent

Execute the plan

One markdown file. The agent works the checkboxes, then checks the result.

Key features

  • Live dashboard

    Files, diffs, tasks, commits, branches, runs, and dependencies, updated as the tree changes.

  • Block review

    Intra-line highlight on the tokens that differ. Stage, unstage, or drop each block.

  • Tasks

    Feature, bug, debt, research, and security, with progress on the dashboard.

  • Git

    Commits, branches, pull, and push. A folder of repositories opens as tiles.

  • Pull requests

    A commit, a GitHub pull request, or a GitLab merge request, with its review comments.

  • Reduced reports

    reslop t prints failures and a short summary. The raw log stays under .log/.

Usage

Install once. Open a change. Hand the plan to the agent.

  • npm i -g reslop

    Install. Node.js 18.15 or newer, on Linux, macOS, or Windows Terminal.

  • reslop

    Live dashboard: files, diffs, tasks, commits, branches, runs, and dependencies.

  • reslop path/to/file

    Review that path. Opens on the file list.

  • reslop 7ac260c

    Open that commit, read-only.

  • reslop https://github.com/org/repo/pull/1

    Review a GitHub pull request or a GitLab merge request, comments included.

  • reslop -n

    Start a new review, even if the latest one is still open.

  • reslop -r

    Read-only.

  • reslop t -- node --test test/auth.test.js

    Run one program. Failures and a short summary on screen, the raw log under .log/.
